- The node backend's wrapper in `~/.local/bin` is no longer written through a
  symlink or over a file Hammunition did not write (#406, D-080 amendment, the
  same rule as #288): it shares the venv writer (directory descriptor,
  `O_EXCL|O_NOFOLLOW` temporary, `link()`/`rename()`, mode 0755 whatever the
  umask), and the plan refuses a foreign symlink, directory, FIFO or file at a
  node unit's command name by name, before any step runs.
  A node block's `entry` and `env` are validated so the wrapper can always be
  recognised and replaced on reinstall: env keys must be shell variable names and
  no value may carry a control character or exceed the wrapper's size.
